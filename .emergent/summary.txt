**PRODUCT REQUIREMENTS**:
The mobile app must have the following features across 6 main tabs:

3.  **Productos (Products):** Display a list of all products (currently 4,349), with functionality to add, edit, and delete them. The list should not be limited and must be performant.

5.  **Cotizaciones (Quotes):** Create quotes by adding multiple products with quantities.
6.  **Import/Export (Critical User Request):**
    *   Export all application data (Products, History, Flows, Quotes) to a single Excel/CSV file.

    *   The import must intelligently handle data: add new products, update prices for existing products (and log the change), and ignore duplicates.
    *   This feature **must work on a mobile device**, allowing the user to save the file locally or share it.
